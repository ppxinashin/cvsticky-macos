# CVSticky v0.1.0

首个原生 macOS 预发布版本，面向 Apple Silicon Mac。这个版本把剪贴板历史、便签、Markdown 编辑预览和 AI 整理整合为独立的 SwiftUI/AppKit 应用。

## 主要变化

- 原生 macOS 应用：使用 SwiftUI、AppKit 和 WebKit 重建，部署目标为 macOS 12，arm64 构建覆盖 M1 及后续芯片。
- 菜单栏与全局快捷键：支持菜单栏入口，默认 `Option+V` 打开剪贴板浮层。
- Liquid Glass 适配：macOS 26 使用系统玻璃效果，较旧系统使用视觉材质降级。
- 新 app 图标：加入符合 macOS 风格的剪贴板/便签图标。

## 剪贴板

- 捕获文本、富文本/HTML、图片和文件。
- 支持搜索、复制、删除、来源应用显示和原文固定。
- 固定记录不会被自动清理；普通记录保留最近 100 条。
- 剪贴板浮层支持方向键选择、Enter 复制、Esc 关闭。
- 支持从剪贴板内容创建便签，或对内容进行 AI 整理。

## 便签

- 支持新建、编辑、自动保存、删除、恢复和彻底删除。
- 支持搜索、标签筛选、颜色筛选、列表/网格切换和右键菜单。
- 最近删除支持清空确认；新建便签取消时会丢弃空草稿。
- ZIP 导入导出，并兼容旧版便签目录迁移。
- 迁移逻辑按便签去重，避免重复复制旧数据。

## Markdown 与编辑体验

- 使用 Milkdown/ProseMirror 所见即所得 Markdown 编辑器。
- 支持 GFM、任务列表、表格、代码块、KaTeX 数学公式和 Mermaid 图表。
- 支持本地图片粘贴/选择，图片保存到便签 `img` 目录并使用安全私有协议预览。
- 编辑器保留常驻格式工具栏和常用快捷键。
- 只读预览中公式和 Mermaid 默认显示渲染结果。
- 外部链接默认用系统浏览器打开。
- Markdown 预览禁用原始 HTML，并加入内容安全策略。

## AI 整理

- 支持 OpenAI Chat Completions 兼容服务。
- API Key 保存到 macOS Keychain。
- 支持连接测试、智能整理、结构化、摘要、任务清单、优化表达和翻译。
- 支持继续生成、目标语言、自定义要求和多个差异化方案。

## 安全与稳定性

- ZIP 导入拒绝符号链接，并限制文件数量与总体积。
- 元数据支持 JSON Base64 载荷，兼容标题和标签中的引号、反斜杠、逗号及换行。
- 本地图片文件名包含空格或非 ASCII 字符时会自动规范化。
- 增加剪贴板保留、元数据往返、旧目录迁移、导入安全、本地图片和任务状态保存等回归测试。

## 安装包

- DMG 现在包含 `CVSticky.app` 和 `Applications` 快捷入口，可直接拖动安装。
- Release 同时提供 `CVSticky-macOS-arm64.dmg` 和 `CVSticky-macOS-arm64.zip`。

## 签名说明

当前预发布包使用 ad-hoc 签名，适合开发验收和内部测试；尚未使用 Apple Developer ID 签名和公证。面向普通用户正式分发时，需要 Developer ID Application 证书并完成 Apple notarization，才能最大程度避免 Gatekeeper 的“无法验证”或“文件损坏”提示。
