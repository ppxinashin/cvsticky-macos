# CVSticky v0.1.1

本次更新完善便签与剪贴板的快捷操作，修复关闭主窗口后无法从 Dock 再次打开的问题，并补充应用内图文帮助与界面细节。面向 Apple Silicon Mac，安装包使用 ad-hoc 签名。

## 新增功能

- 新增便签悬浮窗：在主窗口便签列表向右滑动或打开右键菜单，可将便签置于所有空间和全屏应用之上；同一便签只保留一个悬浮窗口。
- 主窗口便签支持向右滑动，普通便签可执行“悬浮窗”和“删除”，最近删除中的便签可执行“恢复”和“彻底删除”。
- 剪贴板记录支持向右滑动，可快速“存为便签”“AI 摘要”或“删除”；不可处理的图片与文件记录会自动禁用 AI 操作。
- 新增 `Command+?` 应用内图文帮助手册，覆盖主窗口、剪贴板历史、便签编辑、快捷键、主题与数据备份。
- 设置新增“跟随系统主题色”，可在 macOS 系统强调色与自定义主题色之间切换。

## 修复与改进

- 修复关闭主窗口后，点击 Dock 图标无法再次打开主窗口的问题；Dock 重开、菜单栏“打开剪贴笺”和应用激活现在统一恢复主窗口。
- 优化主窗口三栏焦点与选择状态：当前操作列使用主题色，窗口或列失焦后以灰色保留选择，减少误操作。
- 统一主窗口、剪贴板、设置、帮助和 Markdown 编辑器的主题色表现，并让编辑器光标、选区和任务复选框同步更新。
- 删除便签、永久删除、清空最近删除和删除剪贴板记录时补充明确的确认提示。
- 优化便签编辑器工具栏、表格插入和菜单交互，并改善中文输入法候选栏与自定义主题色的兼容表现。
- 更新使用文档和 README，使右滑操作、悬浮便签、系统主题色与应用内帮助说明保持一致。

## 安装包

- 提供 `CVSticky-macOS-arm64.dmg` 和 `CVSticky-macOS-arm64.zip`。
- DMG 使用定制安装布局，包含 `CVSticky.app` 和 `Applications` 快捷入口。
- 打包流程保留 SwiftPM 资源包的完整 `Contents/Resources` 结构，避免 Markdown 编辑器资源在启动时丢失。

## 安装提示

若已安装旧版本，请先退出并删除 `/Applications/CVSticky.app`，再从新 DMG 将应用拖入 `Applications`。当前包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截，请在“系统设置 → 隐私与安全性”中确认打开。
