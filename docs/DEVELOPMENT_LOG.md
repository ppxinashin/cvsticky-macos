# CVSticky for macOS 开发日志

## 2026-07-17：原生 macOS 功能对齐与 Liquid Glass

### 本次目标

- 将 CVSticky 拆分为独立的原生 macOS 项目，原项目后续不再构建 macOS 版本。
- 以原版现有能力为基准补齐功能，不保留仅能演示的占位实现。
- 覆盖所有 Apple Silicon Mac；macOS 26 起启用系统原生 Liquid Glass。

### 技术与兼容策略

- 使用 SwiftUI 构建主界面，AppKit 负责剪贴板、菜单栏、全局快捷键、窗口和系统集成，WebKit 负责 Markdown 预览。
- 部署目标为 macOS 12 Monterey，构建产物仅包含 `arm64` 架构，覆盖 M1 及后续 M 系列芯片。
- macOS 26 及以上通过可用性判断调用系统 `glassEffect`；macOS 12–15 使用 `NSVisualEffectView` 材质降级，业务功能不降级。
- 便签继续采用文件型存储：`~/.cvsticky/<便签>/note.md`，并兼容原有 `for-cvsticky`、`for-clipboard` 元数据。
- API Key 写入 macOS Keychain，不保存在普通配置文件或仓库中。

### 已完成能力

#### 剪贴板

- 捕获文本、富文本/HTML、图片和文件。
- 持久化历史、搜索、删除、复制、来源应用显示和原文固定。
- 普通记录最多保留最近 100 条，已固定记录不受自动清理影响。
- `Option+V` 全局快捷键、菜单栏入口、多显示器居中和置顶浮层。
- 浮层支持方向键选择、Enter 复制、Esc 关闭以及 AI 整理。

#### 便签

- 搜索、标签/颜色筛选、列表/网格切换和右键操作。
- 新建、编辑、自动保存、删除、恢复和彻底删除。
- 从剪贴板原文或 AI 结果创建便签。
- ZIP 导入导出及旧便签目录兼容读取。

#### Markdown

- 原生编辑器与格式工具栏。
- GFM、表格、任务列表及任务状态回写。
- 本地图片、链接、代码高亮、KaTeX 数学公式和 Mermaid 图表。
- 编辑/预览分屏与外部链接默认浏览器打开。
- Marked、KaTeX 和 Mermaid 作为本地资源打包，预览不依赖 CDN。

#### 设置与 AI

- 跟随系统、浅色、深色、主题色和快捷键配置。
- OpenAI Chat Completions 兼容服务地址、模型和流式响应。
- AI 连接测试、整理方案生成和便签转换。
- 数据目录访问、导入和导出入口。

#### 工程化

- Swift Package 测试目标。
- arm64 Release App 打包、临时签名和 ZIP 生成脚本。
- GitHub Actions CI 与按标签发布工作流。
- 独立仓库：<https://github.com/ppxinashin/cvsticky-macos>。

### 数据迁移注意事项

开发验收期间发现旧目录迁移判断会在目标目录已有便签时重复复制数据。代码已改为先检查目标目录中的实际 `note.md`，避免后续再次迁移。

测试期间已经产生的 16 条重复便签没有被自动删除，以避免误删用户数据。它们已被精确识别，但只有在用户明确确认后才应移动到可恢复的废纸篓目录。

## 2026-07-17：合并前审查修复

- 修复编辑状态下从 Markdown 预览勾选任务可能覆盖未保存标题、标签和颜色的问题。
- 旧目录迁移改为逐便签去重，避免目标目录已有部分便签时跳过剩余旧数据。
- 剪贴板清理改为保留全部固定记录，并另外保留最近 100 条普通记录。
- Markdown 预览禁用原始 HTML，增加内容安全策略，并阻止危险链接协议在 WebView 内执行。
- ZIP 导入拒绝符号链接，并限制解压后的文件数量与总体积。
- 元数据新增 JSON Base64 载荷，在保留旧字段兼容性的同时支持标题和标签中的引号、反斜杠、逗号及换行。
- Release 构建从 Git 标签和 GitHub Run Number 注入 App 版本号与构建号。
- 新增剪贴板保留、元数据往返、增量迁移和导入安全回归测试。
- 修复本地图片文件名包含空格或非 ASCII 字符时 Markdown 无法识别的问题；新插入图片统一使用安全文件名，旧便签路径会在读取时自动规范化。
- 编辑页由左右分栏改为上下单列布局，下方预览随 Markdown 输入即时刷新。
- 编辑器进一步替换为基于 Milkdown/ProseMirror 的单区所见即所得 Markdown 编辑器，支持 GFM、任务、表格、公式及图片粘贴/选择，并持续回写纯 Markdown 文件。
- 修复 AppKit 编辑器工具栏程序化插入未通知 SwiftUI Binding，导致图片已复制但保存时正文仍为空的问题。
- 参考旧版 `paste_notes` 恢复常驻格式工具栏和白色便签色，并对齐 ⌘B/⌘I/⌘U/⌘E/⌘K、⌥1/2/3、⌘⇧8/7 快捷键；编辑和预览统一支持 `++下划线++`。

## 2026-07-17：统一编辑体验、图片链路与 AI 增强

- 新建便签默认直接进入编辑状态；任务清单仅点击原生复选框时切换状态，点击文字可定位和编辑。
- 任务清单在只读状态下继续支持单击保存，并使用 macOS 原生尺寸复选框。
- 公式和 Mermaid 在只读状态隐藏源代码编辑区，仅显示渲染结果。
- 将便签格式、列表和插入命令接入 macOS“编辑”菜单及编辑器原生右键菜单。
- 图片选择后立即写入便签 `img` 目录；使用受限的 `cvsticky-img` 私有协议安全读取本地图片，同时在 Markdown 中保留可迁移的相对路径，修复编辑、保存和重新打开后的空白/破图。
- 最近删除右键菜单增加“立即删除”，并保留“删除前确认…”入口。
- 对照旧版补回 AI“继续生成”，新增智能整理、结构化、摘要、任务清单、优化表达和翻译六种方式；支持目标语言、自定义补充要求、多个差异化方案、明确加载状态和生成内容校验提示。
- 按 Apple 编辑菜单、上下文菜单、控件和生成式 AI 指南收敛交互：命令同时出现在主菜单与上下文菜单，破坏性操作置后，AI 输出可继续生成且明确提示用户复核。
- 使用 Xcode beta 完整工具链执行 14 项单元测试，全部通过；Release App 构建及临时签名成功。
- 实机验证新建即编辑、清单单击/文字点击、只读公式、主菜单与右键命令、AI 类型/翻译/自定义要求、最近删除菜单，以及图片插入、保存、状态切换和重启重载。
- “最近删除”侧边栏项目增加右键“清空最近删除…”并使用原生不可撤销确认；单条便签移除无确认的“立即删除”，仅保留“彻底删除…”。
- 第二栏默认宽度收窄为更接近 macOS 便签的列表比例，并限制可拖动最大宽度；便签行分隔线改为统一宽度。
- 新建便签取消时直接丢弃刚创建的草稿，不再留下空便签。
- 任务清单恢复为仅点击原生复选框才切换状态；文字区域保留编辑和选择行为，避免整行点击造成误勾选和脚本异常。
